## Фаза 2 — Безопасность (2–3 дня)

Цель: закрыть самые дешёвые и важные дыры.

- [ ] MQTT: `allow_anonymous false` + `password_file` (Mosquitto); обновить `mosquitto.conf` и env (`MQTT_USERNAME`/`MQTT_PASSWORD` в `server` и `keeper`).
- [ ] Закрыть порты наружу в проде: публиковать только 80/443 (nginx); 4433/4434/1883/4466/4467 — во внутренней сети/security group ВМ.
- [ ] Express: `helmet` (дублирует Nginx, но полезно при dev/прямом запуске) и CSRF (`csurf`/`lusca`) для state-changing запросов.
- [ ] Логирование запросов (`morgan`/`pino`) и ротация логов (docker `logging` `max-size`/`max-file`).
- [ ] Секреты: `secrets.cookie`/`cipher` и SMTP вынести из файлов конфигов в менеджер секретов (Yandex Lockbox) либо генерировать `kratos.yc.yml` из шаблона при деплое (Kratos не подставляет `${VAR}` напрямую).

**Критерий:** анонимная публикация в брокер запрещена; наружу доступны только 80/443; API логирует запросы.
